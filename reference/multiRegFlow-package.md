# multiRegFlow: Guided Multiple Regression for Agricultural Sciences

Integrated workflows for transparent multiple-regression analysis,
diagnostics, multicollinearity, robust covariance inference, model
search, regularization, resampling, flexible alternatives, out-of-sample
validation and scientific interpretation.

## Details

The package is designed for teaching and applied scientific analysis in
agricultural, soil and plant sciences. Specialized estimators are
delegated to established R packages whenever possible. The central
design principle is to separate explanation from prediction and to
preserve an auditable record of statistical decisions.
